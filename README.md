# Portfolio · 可在线编辑的个人作品集网站

一个**高度自定义、可视化在线编辑**的单页个人作品集网站。整个项目只有一个 `index.html`，**零依赖、零后端、零构建**，下载即用，可配合 GitHub Pages 免费部署上线。

> 在线编辑 → 自动保存 → 导出 / 部署，全程不需要写一行代码。

## 特性

### 页面内容（极简浅色风格）
- **导航栏**：站点名、板块锚点、下载简历按钮
- **首屏**：定位标签、姓名、一句话自我介绍、GitHub / 简历按钮，右侧深色代码卡片
- **专业技能**：按组分类的技能标签（语言与框架 / 存储与中间件 / 工程与部署）
- **Vibe Coding 作品**：截图 + 一句话介绍 + 技术/AI 工作流标签 + GitHub 链接的卡片网格
- **实习经历**（可选板块，可一键隐藏）
- **页脚**：版权、邮箱、社交链接

### 在线编辑能力（点击右下角「✎ 编辑」进入）
| 能力 | 说明 |
| --- | --- |
| 改文字 | 所有文字（姓名、介绍、技能、链接文字等）点击即改 |
| 改布局 | 每个板块可上移 / 下移（编号自动重排）、可隐藏 / 显示 |
| 增删内容 | 技能标签、技能分组、作品卡片、实习经历均可添加和删除 |
| 作品排序 | 作品卡片左上角 ‹ › 按钮左右调换顺序 |
| 换截图 | 点击作品缩略图上传本地图片（转 base64 内嵌，无需图床） |
| 改链接 | 所有站外链接旁的 🔗 按钮可配置目标地址（含 GitHub、简历下载链接） |
| 简历下载 | 下载简历按钮支持配置外部直链（OSS / 对象存储 / 网盘），PDF 直链自动带文件名下载 |
| 换主题色 | 工具栏取色器实时更换强调色 |
| 自动保存 | 所有修改存入浏览器 localStorage，刷新不丢失；可一键恢复默认模板 |
| 导出 HTML | 导出干净的单文件成品，且导出的文件里仍能继续编辑 |

## 快速开始

```bash
# 克隆后直接打开
open index.html        # macOS
start index.html       # Windows
```

无需 `npm install`、无需构建工具。

## 部署（GitHub Pages，免费）

1. 将本仓库推送到 GitHub；
2. 仓库 **Settings → Pages → Source** 选择 `main` 分支、`/ (root)` 目录，保存；
3. 几十秒后访问 `https://<你的用户名>.github.io/portfolio/`。

## 使用建议

- 简历 PDF 推荐放在**对象存储（OSS / Cloudflare R2）或 GitHub Release 附件**，把直链配置到「下载简历」按钮（编辑模式点按钮旁的 🔗），访客点击直接下载，无登录、无限速。
- 作品截图建议控制在 2MB 以内（图片以 base64 内嵌在 HTML 中）。
- 大量修改后记得点「导出 HTML」备份，或直接把导出的文件提交回仓库。

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，单文件，无框架、无依赖
- 编辑态通过 `contenteditable` + 事件委托实现，状态持久化到 `localStorage`
- 响应式布局，支持移动端浏览与打印样式
